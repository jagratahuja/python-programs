# Level 3 — Projects and Advanced Experiments

This section contains **larger or more experimental Python programs** created after learning the core concepts of Python.

These programs focus more on **projects, experimentation, and combining multiple concepts together**.

## Topics Covered

* Pygame experiments
* introductory concepts related to AI/ML
* graphical programs
* small interactive projects

## Learning Focus

Level 3 programs emphasize:

* combining multiple Python concepts
* experimenting with external libraries
* building small interactive systems
* exploring creative programming ideas

Compared to earlier levels, these programs tend to involve **more components and external assets** such as images or configuration files.

## Folder Structure

Each project folder may contain:

* `question.md` → explanation of the project
* `code.py` → Python source code
* additional assets (images, data files, etc.) when required

These programs are part of a personal learning archive documenting the progression from basic programming exercises to small independent projects.
