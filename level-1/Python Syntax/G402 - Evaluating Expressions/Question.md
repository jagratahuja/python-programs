# Program G402

## Description
This program focuses on evaluating expressions in Python using different data types.  
It highlights the importance of type conversion when performing arithmetic operations and applies these concepts to real-world scenarios like billing, speed conversion, and geometric calculations.

## Tasks Included
- Task 1: Accept inputs and evaluate an expression, demonstrating issues when using incompatible data types.
- Task 2: Calculate the total bill in a stationery shop using integer and float values.
- Task 3: Convert speed from km/hr to m/s using a mathematical formula.
- Task 4: Calculate the area and perimeter of a circle using user input.

## Concepts Practiced
- Expression evaluation
- Type conversion (`int()`, `float()`)
- Arithmetic operations
- Real-world problem solving
- Working with mixed data types
- Mathematical formulas in Python
