# Program G205

## Description
This program demonstrates two basic programming ideas: accepting user input and swapping values stored in variables.  
First, the program asks the user for their first name and surname and prints a greeting.  
Then it shows how two numeric variables can exchange their values using a temporary variable.

## Tasks Included
- Task 1: Accept a user's first name and surname and print a greeting message.
- Task 2: Demonstrate swapping the values of two variables using a temporary variable.

## Concepts Practiced
- Accepting user input using `input()`
- String concatenation
- Variable assignment
- Swapping values using a temporary variable
- Understanding how variables store values in memory
