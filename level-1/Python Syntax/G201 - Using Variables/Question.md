# Program G201

## Description
This program introduces the concept of variables in Python.  
It demonstrates how variables can store values such as strings and numbers, and how these values can be displayed using the `print()` function.  
The program also shows examples of invalid variable names and explains why they would cause syntax errors.

## Tasks Included
- Task 1: Declare a variable containing a name and print a greeting using that variable.
- Task 2: Declare variables for a favorite color and favorite number, then display them.
- Task 3: Store a number in a variable and print it.
- Task 4: Show examples of invalid variable names using comments (starting with a number, using special characters, and using reserved keywords).
- Task 5: Store and print today's date using three variables: day, month, and year.

## Concepts Practiced
- Variable declaration
- Storing string and numeric values
- Using variables inside `print()` statements
- String concatenation
- Understanding valid and invalid variable names
