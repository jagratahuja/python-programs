# Program G302

## Description
This program demonstrates the use of operator precedence (BODMAS) in Python arithmetic expressions.  
It shows how parentheses change the order of evaluation in calculations. The program also applies arithmetic expressions to practical scenarios such as calculating average marks and computing the total bill for groceries with a discount.

## Tasks Included
- Task 1: Evaluate arithmetic expressions using operator precedence and parentheses to observe differences in results.
- Task 2: Accept marks for five subjects from the user, calculate the total marks, and compute the average score.
- Task 3: Simulate a grocery billing system where the user enters the quantity of vegetables purchased and the program calculates the total cost and the final cost after a 10% discount.

## Concepts Practiced
- Operator precedence (BODMAS)
- Use of parentheses in expressions
- Arithmetic operations in Python
- User input using `input()`
- Type conversion using `int()`
- Calculating totals and averages
- Applying percentage discounts
