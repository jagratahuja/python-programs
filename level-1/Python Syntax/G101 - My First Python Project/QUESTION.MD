# Program G101

## Description

This introductory Python program demonstrates basic Python syntax and the use of the `print()` function.  

The program prints simple messages to the console to illustrate how Python executes commands sequentially.

## Tasks Included

- Task 1: Print a simple greeting message to the console.

- Task 2: Display the classic "Hello World" message.

- Task 3: Print a sentence expressing excitement about learning Python.

- Task 4: Print statements explaining what a computer program and software are.

## Concepts Practiced

- Python syntax basics

- Using the `print()` function

- String literals

- Program execution order
