# Program G204

## Description
This program introduces the concept of building a simple calculator in Python.  
It demonstrates how user input can be converted into integers and used to perform arithmetic operations such as addition, subtraction, and multiplication.

## Tasks Included
- Task 1: Accept two numbers from the user and calculate their sum.
- Task 2: Accept two numbers using `input()` without prompts and display their sum.
- Task 3: Placeholder task (no implementation provided in the program).
- Task 4: Accept two numbers and display the results of addition, subtraction, and multiplication in a formatted output.

## Concepts Practiced
- Accepting numeric input using `input()`
- Converting input values using `int()`
- Performing arithmetic operations (`+`, `-`, `*`)
- Storing results in variables
- Formatting mathematical expressions in output
