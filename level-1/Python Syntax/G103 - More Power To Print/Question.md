# Program G103

## Description
This program demonstrates additional uses of the Python `print()` function, including printing blank lines, combining strings using concatenation, and displaying simple jokes or messages. The tasks show how output formatting works and how strings can be joined together in Python.

## Tasks Included
- Task 1: Print a joke about a spider using a computer, including a blank line for formatting.
- Task 2: Print a joke about climbing a mountain for better Wi-Fi signal.
- Task 3: Demonstrate string concatenation by combining two strings.
- Task 4: Print a full name by concatenating two strings.
- Task 5: Print a joke about making a hot dog stand.

## Concepts Practiced
- Python `print()` function
- Blank line printing using `print()`
- String concatenation using `+`
- Basic console output formatting
