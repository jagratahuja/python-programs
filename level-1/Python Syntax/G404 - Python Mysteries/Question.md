# Program G404

## Description
This program explores how Python handles operators when used with different data types, especially strings.  
It demonstrates how the `+` operator concatenates strings and how the `*` operator repeats them. The program also includes a small interactive task using user input.

## Tasks Included
- Task 1: Observe how `+` and `*` operators behave differently with numbers and strings.
- Task 2: Accept a user's name and display a customized message using string concatenation and repetition.

## Concepts Practiced
- Operator overloading in Python
- String concatenation using `+`
- String repetition using `*`
- Difference between numeric and string operations
- Using user input in formatted output
