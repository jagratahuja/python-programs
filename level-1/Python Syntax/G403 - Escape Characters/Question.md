# Program G403

## Description
This program introduces escape characters in Python and how they are used to format string output.  
It demonstrates how special characters like `\n` (newline) and `\t` (tab) can be used to control text layout and create structured or graphical outputs.

## Tasks Included
- Task 1: Use escape characters like `\n` to print multi-line text using a single print statement.
- Task 2: Create a simple graphical pattern using escape characters such as `\n` and `\t`.

## Concepts Practiced
- Escape characters in Python
- Newline character (`\n`)
- Tab space character (`\t`)
- String formatting
- Creating structured and graphical outputs using text
