# Program G304

## Description
This program demonstrates how variables can change values during program execution.  
Through a sequence of assignments and arithmetic operations, the program shows how the value stored in a variable can depend on previously stored values and calculations.

## Tasks Included
- Task 1: Perform a sequence of calculations using three variables (`first`, `second`, and `third`) and observe how their values change step-by-step.
- Task 2: Perform multiple arithmetic operations on a single variable (`x`) and display the final value.

## Concepts Practiced
- Variable reassignment
- Arithmetic operations
- Step-by-step value changes in variables
- Understanding how program execution updates memory values
