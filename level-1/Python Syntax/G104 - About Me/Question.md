# Program G104

## Description
This program demonstrates simple output statements in Python by printing personal information.  
It uses multiple `print()` statements to display sentences describing a student's interests, favorite subjects, and hobbies.

## Tasks Included
- Task 1: Print several sentences describing personal details such as grade, favorite subject, favorite language, hobbies, and interest in coding.

## Concepts Practiced
- Python `print()` function
- Sequential program execution
- Displaying multiple lines of text
- Basic program structure
