# Program G202

## Description
This program introduces user interaction in Python using the `input()` function.  
It demonstrates how programs can accept data from users, store it in variables, and display the information back using `print()` statements.

## Tasks Included
- Task 1: Accept a user's name as input and print a greeting.
- Task 2: Accept a surname and display a greeting using both the name and surname.
- Task 3: Accept a name from the user, display it, then overwrite the variable with a new value and print it again.
- Task 4: Accept multiple pieces of user information including name, age, grade, and hobbies.
- Task 5: Accept input from the user and print the same text back (echo functionality).

## Concepts Practiced
- Using the `input()` function
- Storing user input in variables
- Displaying user-provided data
- Variable reassignment
- Basic interactive programs
