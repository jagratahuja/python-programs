# Program G102

## Description
This program demonstrates how Python can be used to create simple text-based art using the `print()` function.  
Each task prints a small ASCII-style face or character by arranging symbols and characters across multiple lines.

## Tasks Included
- Task 1: Print a simple face using caret (`^`) and dash (`-`) characters.
- Task 2: Print a face using zeros for eyes and simple symbols for the nose and mouth.
- Task 3: Print another face using `@` symbols for the eyes and a vertical bar for the nose.
- Task 4: Print a small ASCII-style bunny using parentheses, slashes, and underscores.

## Concepts Practiced
- Python `print()` statements
- Multi-line output
- ASCII/text art creation
- Understanding program output formatting
