# Program G303

## Description
This program demonstrates a simple temperature conversion utility in Python.  
It accepts temperature values from the user and converts them between Celsius and Fahrenheit using standard mathematical formulas.

## Tasks Included
- Task 1: Accept a temperature value in Celsius and convert it to Fahrenheit.
- Task 2: Accept a temperature value in Fahrenheit and convert it to Celsius.

## Concepts Practiced
- Accepting numeric input using `input()`
- Converting input values using `int()`
- Using arithmetic formulas for temperature conversion
- Printing calculated results
