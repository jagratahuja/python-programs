# Program G203

## Description
This program demonstrates how Python uses variables and computer memory to store and manipulate values.  
It includes examples of storing user input, performing arithmetic operations, converting input values to integers, and displaying calculation results.

## Tasks Included
- Task 1: Accept a lucky number from the user, display it, then reassign the variable to the result of an arithmetic operation.
- Task 2: Perform and display basic arithmetic operations including addition, subtraction, and multiplication using variables.
- Task 3: Accept two numbers from the user and multiply them.
- Task 4: Accept two numbers from the user and subtract the second number from the first, displaying the formatted result.

## Concepts Practiced
- Variable storage in memory
- Reassigning variable values
- Arithmetic operations (`+`, `-`, `*`)
- Converting user input using `int()`
- Using variables in mathematical expressions
- Printing formatted calculation results
