# Program G305

## Description
This program demonstrates real-world problem solving using arithmetic expressions in Python.  
It applies mathematical formulas to calculate height using proportional relationships, speed using distance and time, and average speed across multiple segments.

## Tasks Included
- Task 1: Calculate the height of a cliff using the concept of proportional shadows.
- Task 2: Calculate and compare the cycling speeds of two individuals based on distance and time taken.
- Task 3: Calculate total distance, total time, and average speed for a journey involving uphill and downhill travel.

## Concepts Practiced
- Applying mathematical formulas in programming
- Arithmetic operations (`+`, `-`, `*`, `/`)
- Real-world problem solving using variables
- Speed calculation (Distance / Time)
- Average speed calculation
- Working with multiple variables and expressions
