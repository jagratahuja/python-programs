# Program G401

## Description
This program introduces the concept of data types in Python.  
It explains different types such as String, Integer, Float, and Boolean through examples and interactive tasks. It also demonstrates how to identify data types using the `type()` function.

## Tasks Included
- Task 1: Identify and categorize values into appropriate data types (String, Integer, Float, Boolean).
- Task 2: Declare variables of different data types and use the `type()` function to check their types.
- Task 3: Identify the correct data type for real-world examples such as name, age, and height.

## Concepts Practiced
- Data types in Python (String, Integer, Float, Boolean)
- Variable declaration
- Using the `type()` function
- Understanding real-world mapping of data types
