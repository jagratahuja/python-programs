# Program G101 (Conditional Branching)

## Description
This program introduces conditional branching in Python using `if-else` statements.  
It demonstrates how programs can make decisions based on user input and logical comparisons, producing different outputs depending on conditions.

## Tasks Included
- Task 1: Accept user input (yes/no) and display different outputs based on the response.
- Task 2: Use comparison operators to evaluate expressions and understand boolean results.
- Task 3: Compare two numbers entered by the user and determine the greater value.
- Task 4: Determine whether a photo frame is square or rectangular based on its dimensions.

## Concepts Practiced
- Conditional statements (`if-else`)
- Boolean values (`True`, `False`)
- Comparison operators (`==`, `!=`, `<`, `>`, `<=`, `>=`)
- User input handling
- Decision making in programs
