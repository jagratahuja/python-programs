# Program G102 (Conditional Branching)

## Description
This program builds on conditional statements by introducing multiple condition checks using `if-elif-else`.  
It demonstrates how to evaluate different scenarios such as number classification, performance evaluation, and geometric conditions.

## Tasks Included
- Task 1: Determine whether a number is positive, negative, or zero.
- Task 2: Evaluate a student's marks and display feedback based on performance.
- Task 3: Check whether a triangle is equilateral using multiple conditions.
- Task 4: Identify which sides of a triangle are equal using multiple `elif` conditions.

## Concepts Practiced
- Conditional branching (`if`, `elif`, `else`)
- Evaluating multiple conditions
- Comparison operators
- Logical flow control
- User input handling
