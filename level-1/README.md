# Level 1 — Python Fundamentals

This section contains **beginner-level Python programs** written while learning the core fundamentals of programming.

These programs focus on understanding how Python works and building a strong base in logic and syntax.

## Topics Covered

* Python syntax
* Conditional branching
* Loops
* Built-in functions
* Drawing using Turtle graphics
* Functions in Python
* Small creative exercises

## Learning Focus

Level 1 programs emphasize:

* understanding program flow
* writing basic logic
* interacting with user input
* experimenting with simple graphical output

Many files contain **multiple small exercises** within a single program file.

## Folder Structure

Each program folder contains:

* `question.md` → description of the exercise or problem
* `code.py` → the original Python code written for the exercise

## Note

All programs in this repository were written independently during my early programming learning journey and are preserved **without modification** to reflect the original learning process.
