# Level 2 — Intermediate Python Concepts

This section contains **intermediate-level Python programs** that build upon the foundational concepts introduced in Level 1.

The focus shifts toward working with **data structures, modular programming, and simple graphical interfaces**.

## Topics Covered

* Lists and dictionaries
* Data structures
* Tkinter GUI programs
* Functions and modular code
* Search and sorting algorithms

## Learning Focus

Level 2 programs emphasize:

* structured problem solving
* working with collections of data
* designing reusable functions
* experimenting with simple graphical user interfaces

Some exercises also introduce **algorithmic thinking** through basic searching and sorting techniques.

## Folder Structure

Each program folder contains:

* `question.md` → description of the exercise or task
* `code.py` → the original Python implementation

## Note

All programs are preserved in their **original form** to reflect the progression of learning and experimentation during the course.
